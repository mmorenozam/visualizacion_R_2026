Autoevaluación Módulo 3

Visualización de datos con {ggplot2}

Ocho preguntas cortas sobre el Módulo 3, dos por cada objetivo de la sesión. Tienes dos intentos por pregunta; después verás la respuesta y una explicación. Es anónima: no se guarda ni se envía nada.

Objetivo 1: Elegir el gráfico

1. Quieres ver si la masa corporal está relacionada con el largo de la aleta. ¿Qué gráfico usas?

Dos variables numéricas: gráfico de dispersión. Si además quieres la tendencia, agrega geom_smooth().

2. Quieres comparar la distribución de la masa entre las tres especies. ¿Qué opción es la menos** adecuada?**

Una numérica frente a una categórica: cajas, violines, densidades o puntos. Una línea une valores en orden, y aquí el orden de las filas no significa nada.

Objetivo 2: Figuras con estadísticos

3. ¿Qué dibuja stat_summary(fun.data = mean_se)?

stat_summary() calcula un resumen por grupo; mean_se devuelve la media y ± un error estándar. Para la desviación estándar, mean_sdl (con fun.args = list(mult = 1)).

4. En una figura, ¿por qué hay que decir si las barras de error son la desviación estándar o el error estándar?

El error estándar es \(s/\sqrt{n}\): con 70 pingüinos, unas 8 veces más pequeño que la desviación estándar. Sin aclararlo, el lector no puede interpretar las barras.

Objetivo 3: Facetas, escalas, etiquetas y temas

5. ¿Qué hace facet_wrap(~ island)?

Las facetas dividen el gráfico en paneles, uno por nivel. facet_grid(filas ~ columnas) hace una cuadrícula con dos variables.

6. ¿Por qué conviene usar paletas como viridis u Okabe-Ito?

Alrededor de 1 de cada 12 hombres tiene alguna forma de daltonismo; el rojo y el verde son la combinación más problemática. Estas paletas están diseñadas para seguir siendo distinguibles.

Objetivo 4: Exportar gráficos

7. ¿Por qué fijar width, height y units en ggsave()?

Sin tamaño fijo, ggsave() usa el del panel de gráficos. Fijándolo, el mismo código produce siempre la misma figura, con el texto del tamaño que esperas.

8. Para una publicación que pide figuras que se vean nítidas a cualquier tamaño, ¿qué formato eliges?

Los formatos vectoriales guardan las formas, no los píxeles: se amplían sin perder nitidez. Para Word y presentaciones, un png a 300 dpi suele bastar.
