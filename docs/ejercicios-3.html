Estos ejercicios siguen el Módulo 3. Los de gráficos corren en tu navegador; los de exportar se hacen en RStudio, porque crean archivos en tu computador. Donde veas ____, complétalo. ¿Te atascaste? Abre la pestaña Pista. Las soluciones se publican después de la sesión.

Antes de empezar
  • La primera vez, cargar R, {dplyr} y {ggplot2} en el navegador puede tardar uno o dos minutos.
  • La tabla pinguinos ya está cargada, sin las 11 filas de sexo desconocido (333 pingüinos) y con species, island y sex como factores.
  • Para la serie de tiempo usamos economics, que viene con {ggplot2}.

En clase avanzamos por las partes 1 a 3. Completa todos los ejercicios de esta página antes de la próxima sesión, incluida la Parte 4: Más práctica.

library(tidyverse)
pinguinos <- read_csv("datos/pinguinos.csv") |> filter(!is.na(sex))

grafico <- ggplot(pinguinos, aes(x = bill_length_mm, y = bill_depth_mm, color = species)) +
  geom_point() +
  scale_color_viridis_d() +

  theme_minimal()

Ejercicio 4.5: Combinar gráficos con {patchwork}

En RStudio, combina en una sola figura un diagrama de caja de la masa por especie y el gráfico de dispersión aleta y masa, con las letras A y B, y guárdala.

  • Ejercicio
  • Pista
  • Solución

Este ejercicio se hace en RStudio, en tu proyecto del curso: copia el código, complétalo y córrelo (o renderiza el documento).

# install.packages("patchwork")   # solo la primera vez
library(tidyverse)
library(patchwork)
pinguinos <- read_csv("datos/pinguinos.csv") |> filter(!is.na(sex))

g1 <- ggplot(pinguinos, aes(x = species, y = body_mass_g)) + geom_boxplot()
g2 <- ggplot(pinguinos, aes(x = flipper_length_mm, y = body_mass_g, color = species)) + geom_point()

figura <- g1 ____ g2 + plot_annotation(tag_levels = "____")
figura
ggsave("resultados/figura_combinada.png", figura, width = 24, height = 10, units = "cm", dpi = 300)

Con {patchwork}, g1 + g2 pone los gráficos lado a lado y g1 / g2, uno sobre otro. plot_annotation(tag_levels = "A") agrega las letras.
